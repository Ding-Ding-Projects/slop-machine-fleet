# TabStrip

Every page opens as a browser-style tab: pin, reorder, group with colours, overflow, and search tabs.

- **Material 3 primitive:** Tabs (secondary) restyled as browser tabs, with menus for management
- **Covers:** `tabs`, `regex-search`, `appearance-editor`, `context-menus`

## Provide
- Tabs with icon and title; selected tab joins the page surface; groups as coloured labels with a matching top stripe.
- Right-click: full tab menu including "Edit tab appearance…".

## Do
- Persist order, pins, groups and collapsed state.
- Keep a tab search with its own regex builder.

## Don't
- Don't replace tabs with one long scrolling page.
