# NavigationRail

The left rail holds primary destinations; each opens or focuses a tab.

- **Material 3 primitive:** Navigation rail with FAB and badges
- **Covers:** `workflow-navigation`, `tabs`

## Provide
- Five to seven destinations with outlined icons that fill when active, a label under each, badges for counts.

## Do
- Put New worker as the rail FAB.

## Don't
- Don't nest destinations inside the rail.
