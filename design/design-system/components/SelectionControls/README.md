# SelectionControls

Switches for instant on/off settings, discrete sliders for levels, checkboxes for options inside a form.

- **Material 3 primitive:** Switch, slider (Expressive), checkbox
- **Covers:** `settings-explanations`, `material-design`

## Provide
- Each control sits in a row with a label and a one-line explanation of its effect.

## Do
- Show the current value as a number next to a slider.

## Don't
- Don't hide the effect of a switch in a help page.
