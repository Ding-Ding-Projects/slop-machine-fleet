# FunnyLevel

Two independent funny-level sliders, shipped at 5, plus the dialog emoji switch, with a live preview proving facts stay identical.

- **Material 3 primitive:** Slider, switch, card
- **Covers:** `funny-emoji`, `language`

## Provide
- Two sliders with values, a preview card showing levels 1 and 5 on the same message, and the emoji switch.

## Do
- Apply to every message category, including errors and security copy.

## Don't
- Don't let the level change a number, name or instruction.
- Don't put emoji in buttons or labels.
