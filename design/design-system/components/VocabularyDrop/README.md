# VocabularyDrop

Personal wording import by file picker or drop, applied locally with a validation summary and a reset.

- **Material 3 primitive:** Drop zone composition with buttons
- **Covers:** `personal-vocabulary`, `vocabulary-drop-apply`

## Provide
- The drop target with a file picker, a result summary (applied, skipped, invalid) and reset.

## Do
- Validate before applying and show what changed.

## Don't
- Don't send the file anywhere.
