# ScheduledSettings

Any appearance or customization value can follow a schedule or an external settings source.

- **Material 3 primitive:** List with switches
- **Covers:** `scheduled-settings`

## Provide
- One row per schedule: icon, the value, when or which source, an enable switch.

## Do
- Show which schedule set the current value.

## Don't
- Don't silently override a manual change; show it as paused until the next window.
