# Notifications

Messages never block work: a snackbar for the moment, and a notification centre that keeps every message to review, filter and act on.

- **Material 3 primitive:** Snackbar, list in a side sheet or menu
- **Covers:** `notifications`, `funny-emoji`, `action-sound-effects`

## Provide
- A one-line message, one action at most, a dismiss button; the same message lands in the centre with time and source.

## Do
- Respect the funny level in copy and the emoji switch in dialogs only.

## Don't
- Don't use modal alerts for status.
