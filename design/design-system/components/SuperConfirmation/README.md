# SuperConfirmation

The destructive-action gate: an exact summary of what goes, then two independent keys (type the name and tick the acknowledgement) before the button arms.

- **Material 3 primitive:** Dialog (basic) with text field and checkbox
- **Covers:** `super-confirmation`, `bulk-actions`

## Provide
- The exact resources and sizes, the name to type, the acknowledgement, and a danger button that stays disabled until both keys are set.

## Do
- Default focus on Cancel.

## Don't
- Don't offer a do-not-ask-again option.
