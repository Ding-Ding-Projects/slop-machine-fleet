# CostReview

The required review before any resource is created: count against the cap, estimate with its source and time, storage, and what is not included.

- **Material 3 primitive:** Card (high) with progress ring and buttons
- **Covers:** `honest-monetization`, `guided-forms`, `functional-ui`

## Provide
- Hourly estimate with source and fetch time, cap usage as a ring and a sentence, storage line, excluded costs line, and one launch button that names the count.

## Do
- Block the launch, with the reason, when it would exceed the cap.

## Don't
- Don't round a cost to zero or omit what is excluded.
