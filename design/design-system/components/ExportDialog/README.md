# ExportDialog

Export everything in every format the data allows, stating exactly what is included and excluded.

- **Material 3 primitive:** Dialog with filter chips
- **Covers:** `exports`, `local-history`

## Provide
- Format chips, an included/excluded sentence, and an export button naming the format.

## Do
- Write atomically to a destination the user picks.

## Don't
- Don't include secrets or codes.
