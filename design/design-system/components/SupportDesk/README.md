# SupportDesk

A local recovery desk: each ticket walks a guided route for a lockout or stuck state and keeps its record.

- **Material 3 primitive:** List with status chips
- **Covers:** `support-tickets`, `unlock-ladder`, `progress-recovery`

## Provide
- Ticket title, current step, status, and the guided route.

## Do
- Offer the desk from every lock and every failure.

## Don't
- Don't send ticket contents off the machine.
