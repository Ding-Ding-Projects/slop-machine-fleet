# FilterPanel

Statistics and filters share one panel that collapses to its header, with the collapsed state remembered.

- **Material 3 primitive:** Card with chips and an icon button
- **Covers:** `collapse-filters`, `functional-ui`

## Provide
- Counts that come from real data, filter chips, a clear action and a collapse toggle with `aria-expanded`.

## Do
- Remember collapsed state per page.

## Don't
- Don't show invented statistics.
