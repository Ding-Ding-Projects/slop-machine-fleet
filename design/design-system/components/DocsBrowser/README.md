# DocsBrowser

Task-oriented documentation bundled for offline use, with guided walkthroughs.

- **Material 3 primitive:** Navigation list and typography
- **Covers:** `offline-docs`, `feature-docs`

## Provide
- Task list, article, walkthrough button, the documented version.

## Do
- Link each article to the control it explains.

## Don't
- Don't ship a raw file browser as docs.
