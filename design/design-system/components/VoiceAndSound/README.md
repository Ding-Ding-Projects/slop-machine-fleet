# VoiceAndSound

Spoken narration with separate voice pickers per language and a switch for polished action sounds.

- **Material 3 primitive:** Card with menus, icon buttons, switches
- **Covers:** `narration`, `action-sound-effects`

## Provide
- Narrator switch, a voice picker per language (each with search) and preview, and the sounds switch.

## Do
- Never read secrets aloud.

## Don't
- Don't autoplay sound on launch.
