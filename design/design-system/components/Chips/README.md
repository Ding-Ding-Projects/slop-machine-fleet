# Chips

Chips filter the fleet and offer quick actions; selected filter chips fill with `secondary-container`.

- **Material 3 primitive:** Filter chips and assist chips
- **Covers:** `collapse-filters`, `functional-ui`

## Provide
- A short label; a leading check appears only when selected.
- Filter chips map to real values from the fleet (states, regions, tags).

## Do
- Show saved views as chips beside filters.

## Don't
- Don't use chips for status; use StatusChip.
