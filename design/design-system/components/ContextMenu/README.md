# ContextMenu

Right-click on any element opens its menu: a filter field with its own regex builder, real actions with shortcuts that work, then appearance and lock entries.

- **Material 3 primitive:** Menu
- **Covers:** `context-menus`, `menu-shortcuts`, `appearance-editor`, `element-locks`

## Provide
- Items with icon, label and the shortcut that actually triggers it; destructive items last in `error`.

## Do
- Include "Edit appearance…" and "Lock…" on every element.

## Don't
- Don't list shortcuts that are not wired.
