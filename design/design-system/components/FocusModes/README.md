# FocusModes

Selectable ADHD modes that change layout density and flow, not content.

- **Material 3 primitive:** Selectable cards
- **Covers:** `adhd-modes`

## Provide
- Mode cards with icon, name and a one-line effect; selection persists.

## Do
- Preview the effect before applying.

## Don't
- Don't hide safety information in any mode.
