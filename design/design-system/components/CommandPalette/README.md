# CommandPalette

The command palette on Ctrl+Shift+F: settings change live inside results, and Enter teleports to the exact element and highlights it.

- **Material 3 primitive:** Search view in a dialog, list items with embedded controls
- **Covers:** `command-palette`, `regex-search`, `menu-shortcuts`

## Provide
- Results grouped as Settings (with live controls), Go to (element paths), Workers, Actions; each with its shortcut.

## Do
- Highlight the target element after teleporting.

## Don't
- Don't bind the palette to any other shortcut.
