# SegmentedButton

A compact choice between a few views or modes.

- **Material 3 primitive:** Segmented button
- **Covers:** `material-design`

## Provide
- Two to five options, each with a label and optional icon; `aria-pressed` on the selected one.

## Do
- Use for view switches and language mode.

## Don't
- Don't use for more than five options; use a menu with search.
