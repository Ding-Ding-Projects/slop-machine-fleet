# ToolsHub

The tools hub lists the built-in tools; each tool gets its own full screen design in a later pass.

- **Material 3 primitive:** Cards
- **Covers:** `file-converter`, `base64-tools`, `minecraft-server-manager`, `minecraft-world-generator`, `ollama-suite`, `external-editor`, `drawesome-drawing`

## Provide
- Icon, name and a one-line purpose per tool; opening one creates a tab.

## Do
- Keep every tool local.

## Don't
- Don't ship a tool card without the working tool.
