# SchoolMode

The universal, renamable mode: once on, only its chosen name appears anywhere, playful features behave as not installed, and turning it off needs the shared unlock.

- **Material 3 primitive:** Card with switch and buttons
- **Covers:** `school-mode`, `language`, `unlock-ladder`

## Provide
- The user's chosen name, the switch, rename, the unlock route, and the honest reset line.

## Do
- Use only the chosen name in every label once renamed.

## Don't
- Don't claim it is a security boundary.
