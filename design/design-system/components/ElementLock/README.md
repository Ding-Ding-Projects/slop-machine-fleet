# ElementLock

Any element can carry its own toy lock with an independent credential; the forgot route leads into the unlock ladder.

- **Material 3 primitive:** Card with a scrim overlay, text input, buttons
- **Covers:** `element-locks`, `unlock-ladder`, `authenticator`, `support-tickets`

## Provide
- The locked element blurred under a veil, the credential entry, an authenticator option and the recovery route.

## Do
- Say plainly it is a toy lock and how it can be reset.

## Don't
- Don't block the whole window for one element.
