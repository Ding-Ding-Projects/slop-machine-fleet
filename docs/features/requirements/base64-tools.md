# Full local Base64 toolkit

Every user-facing application and GitHub Pages ships a local Base64 encoder and decoder for text and files: standard, URL-safe and MIME variants, padding and line-length options, strict or lenient decoding with exact error offsets, selectable text encodings, and data: URL building and parsing. Files of any size stream with progress, pause and cancel, are verified by a SHA-256 round trip, and decode back with detected type and a safe sandboxed preview. Import from file, clipboard or paste; export as file, clipboard, data: URL, JSON record or bulk .zip; every conversion is a history entry with unlimited undo. Nothing leaves the device.
