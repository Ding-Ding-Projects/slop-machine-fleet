# Accessibility, sizing, and layout without layout clipping defect

Every application and GitHub Pages carries a full accessibility-tools menu, visible by default and reachable everywhere while enabled, with text size, contrast, reduced motion, visible focus, larger targets, keyboard help and supported user-initiated read-aloud excluding secrets. A separated hide action requires explicit confirmation with Cancel initially focused and preserves preferences; searchable settings remains reachable when locked, restores visibility immediately, and reset makes the entry visible, with the exact capability and negative-regression inventory in everywhere-reachable accessibility tools.
