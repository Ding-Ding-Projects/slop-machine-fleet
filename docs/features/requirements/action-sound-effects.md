# Polished action sounds with a Settings switch

Every application provides short, polished sounds for selected meaningful actions and real outcomes. A visible localized, keyboard-accessible Settings switch turns all action cues off, persists across restart and applies immediately. Centralized non-blocking playback respects existing mute, volume, reduced-sound and quiet-hours preferences while visible and assistive feedback remains complete without audio.

## Applicability

Applicable product surfaces must implement this behavior individually. A feature on one surface does not establish delivery on another.
