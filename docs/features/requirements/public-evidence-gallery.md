# Public screenshot gallery at usage limit reached

At each usage limit reached pass one gpt-6-luna implementation subagent creates or updates a dedicated public repository and public GitHub Pages carrying every reviewed, publishable, genuine screenshot of the current project, while the source repository stays private. Pixels, captions, metadata, and file names are reviewed, private vocabulary and private details are excluded, and capture dates come only from validated provenance. Public visibility, the live GitHub Pages, and each image are verified separately from the source push.
