# Export everything, in every format

Every record, view, list, log, document, setting, and generated artifact a application owns is exportable in every coding format that can faithfully carry it, chosen per datum, with any loss stated before the export runs. Exports are complete, re-importable where the shape allows, and state their encoding, line endings, and schema version. Archives are ZIP or 7z with the full 7z option set, encrypted headers included, relative paths, and no secret the surrounding flow has not marked as sensitive.

## Applicability

Applicable product surfaces must implement this behavior individually. A feature on one surface does not establish delivery on another.

## Current delivery state

Unfinished. No complete implementation or runtime acceptance is claimed. Review the delivery inventory for evidence as work lands.

## Acceptance

Verify the real behavior, localization, accessibility, persistence and reset where state exists, failure and recovery paths, and genuine built-surface evidence. Source presence alone is insufficient.
