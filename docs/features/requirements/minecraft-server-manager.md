# Full Minecraft server creator and manager

Every application ships a full server creator, flavour/custom-plugin installer and manager through interactive rich GUI controls on local Microsoft Windows processes, local Docker, SSH processes and SSH Docker. Complete Java/Bedrock version discovery includes historical/current and development channels where server distributions exist, with version-bound configuration, commands, runtimes, compatibility and honest unavailable gaps. Reusable official references, hand-written inventories and real built-GUI acceptance prevent a version picker or generic textbox editor from masquerading as full support.

Applicable product surfaces must implement this behavior individually. A feature on one surface does not establish delivery on another.
