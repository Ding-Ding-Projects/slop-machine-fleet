# Wiki and GitHub Pages source kept current

Every project-changing task updates the GitHub wiki and any existing GitHub Pages source. Public repository applications create the mandatory GitHub Pages when the host supports it; private repositories deliver their GitHub Pages as a packaged desktop application rather than a hosted site and keep it current in the same task. Public application GitHub Pages sites contain complete articles and wiki content directly, with verified internal navigation; optional source links never substitute for content. Publishing either one never sets off an endless loop of base repository pushes.

## Applicability

Applicable product surfaces must implement this behavior individually. A feature on one surface does not establish delivery on another.

## Current delivery state

Unfinished. No complete implementation or runtime acceptance is claimed. Review the delivery inventory for evidence as work lands.

## Acceptance

Verify the real behavior, localization, accessibility, persistence and reset where state exists, failure and recovery paths, and genuine built-surface evidence. Source presence alone is insufficient.
