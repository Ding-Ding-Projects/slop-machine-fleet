# Minecraft world generator in every server tab

Every Minecraft server tab includes a world generator: full typed world customization from per-version jar extraction, size of world to generate defaulting to 100 × 100 chunks with a drawing canvas for a custom area, and output to a Folder or ZIP through a Browse dialog. Generation runs the exact version's server only after in-app EULA acceptance and pre-generates the chosen area in bounded batches.
