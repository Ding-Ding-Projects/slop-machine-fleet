# A Material Design 3 GitHub Pages carrying every feature

Every public repository application ships a Material Design 3 GitHub Pages; private repositories deliver the same GitHub Pages as a packaged desktop application instead of a hosted site (private-documentation-package). Each existing GitHub Pages is a landing, documentation, download, status, settings, and link surface, says so visibly, and is never the primary runtime, a playable game, or an embedded imitation of the product. It strictly carries every user-facing feature in this catalogue as a GitHub Pages equivalent operating on its own content and per-visitor local storage, guarded by a hand-written enumeration that fails the docs build when one is missing, and it is as customizable and tabbed as the application. It presents every feature the project has, bundles every asset locally with no CDN, hosted font, or analytics, states the version it documents, and never presents unreleased work as shipped.

## Applicability

Applicable product surfaces must implement this behavior individually. A feature on one surface does not establish delivery on another.
