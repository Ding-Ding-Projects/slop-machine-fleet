# Verified installer download on Home

When a verified installer exists, the GitHub Pages's Home page carries a direct, clearly labelled download button using the immutable release asset URL from the validated release manifest, showing the version and platform and operable by keyboard and screen reader. Until publication is verified the button is absent, never pointing at a candidate or guessed URL. A private repository’s packaged GitHub Pages follows the same rule against its verified private release asset.

## Applicability

Applicable product surfaces must implement this behavior individually. A feature on one surface does not establish delivery on another.
