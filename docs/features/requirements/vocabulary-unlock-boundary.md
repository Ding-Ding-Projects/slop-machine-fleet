# private vocabulary only after authentication

On every GitHub Pages or other website that uses the private vocabulary, all unauthenticated HTML, metadata, API error text, accessible names, registration and sign-in copy, and pre-authentication assets use ordinary language, and the private vocabulary unlocks only after authentication succeeds, with Slop Machine alone public. A current request naming one exact term and one exact private surface authorizes only that literal on that surface, never any public, unauthenticated, exported, logged, or synchronized content.

## Applicability

Applicable product surfaces must implement this behavior individually. A feature on one surface does not establish delivery on another.
