# Per-control info icon buttons

Every capable control in every application and GitHub Pages has its own compact locally bundled Material Design 3 info icon button directly above the target. It opens optional, target-specific contextual explanation and guided steps with the required worked example and isolated playground; it never starts a real operation or copies live private values. This identity is tracked separately from guided-forms, with an explicit per-control inventory, localized accessible naming, keyboard operation, focus return, narrow-layout behavior and native/browser target-size equivalents. A global Help destination, tooltip, generic paragraph or source-only declaration does not replace a rendered working button.

## Applicability

Applicable product surfaces must implement this behavior individually. A feature on one surface does not establish delivery on another.

## Current delivery state

## Acceptance

Verify the real behavior, localization, accessibility, persistence and reset where state exists, failure and recovery paths, and genuine built-surface evidence. Source presence alone is insufficient.
