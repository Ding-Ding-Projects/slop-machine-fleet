# Support Tickets recovery desk

A locked-out person reaches **Support Tickets** from the unlock prompt, the lock setting, and Help: a playful local ticket desk whose resolution opens the application-data folder in the platform file manager with the exact path shown and copyable. It never deletes anything itself, and any in-application deletion goes through super confirmation. One plain line outside the comedy, unstyled by the funny level, states that nothing is sent anywhere and nobody is reading, and no real company's support branding or human response time is ever imitated.
