# Public dim-sum photo references in releases

Consumer GitHub releases reference published originals in the owning public dim-sum catalogue, using authoritative bilingual names and an unused code name when a dish can be resolved. Never track copied photos or a second catalogue authority in a consumer repository, or attach duplicate photos or photo archives to its releases; the dedicated source clause retains its bounded offline metadata and application-data cache allowances. When no unused dish can be resolved because the catalogue is unavailable, publish with the version alone and say so, without delaying the release. The owning public photo repository alone retains image generation, validation, release volumes and any temporary catalogue-completion exception.
