# Fleet implementation

## Objective

Deliver a shared authenticated desktop and self-hosted control plane for one Windows Server 2025 EC2 machine per coding worker, with guided Codex login and pairing, interactive GitHub CLI login, task dispatch and bulk management.

## Current state

Implementation is in progress in isolated service, worker, interface and delivery lanes. Initial API and security boundaries are recorded. No cloud resources have been launched. No runtime, installer, pairing or complete required-feature acceptance is claimed.

- Real task dispatch, interruption, approvals and preservation.
- Per-target bulk outcomes and retained workspace data by default.
- Complete applicable required-feature inventory with honest unfinished states.
